                                                           Problem Statement
Create a C program called LOOPLAB to analyse daily expenses. Repeatedly read expense amounts until the user enters 0. For each positive
amount, classify it using the rules below, update counts and totals, and finally display a summary. Use loops, conditional statements, arithmetic
operators, and variables. Do not use arrays, functions, or strings.
                                                              algorithm
1.start. 
2.initialize all counts and totals to zero.
3. Read expenses until the user enters 0.
4. If the expense is negative, display an error message.
5. Classify positive expenses as Small, Medium, or Large and update their counts and totals.
6. Display the total expenses and category summary.
7. Calculate the average if valid expenses exist; otherwise, display a message. 
8.stop.
