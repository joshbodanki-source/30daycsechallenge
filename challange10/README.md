## Problem Statement

Develop a menu-driven C program to monitor environmental conditions across five campus zones: Academic Block, Hostel, Library, Cafeteria, and Sports Area. The program collects temperature, humidity, and Air Quality Index (AQI) readings for seven days and analyzes the data to identify environmental concerns. It calculates zone-wise averages, detects risk days, generates a Green Index, ranks the zones, and provides practical recommendations for improving campus environmental conditions.

## Objective

To understand the use of two-dimensional arrays, user-defined functions, conditional statements, loops, and menu-driven programming in C. The objective is to analyze environmental data, calculate averages, identify environmental risks, rank campus zones, and suggest suitable improvements.

## Algorithm

1. Start the program and initialize the required arrays and variables.
2. Display a menu with options to input/update data, display data, calculate zone-wise averages, detect risk days, calculate Green Index and ranking, and display recommendations.
3. Read and validate temperature, humidity, and AQI readings for all five zones over seven days.
4. Display the environmental readings in a tabular format.
5. Calculate the average temperature, humidity, and AQI for each zone.
6. Detect risk days based on the given temperature, humidity, and AQI conditions.
7. Calculate the Green Index for each zone using the given scoring formula and display the ranking from highest to lowest.
8. Generate practical recommendations for each zone based on average readings and detected risk days.
9. Repeat the menu until the user selects the Exit option.
10. Stop the program.
