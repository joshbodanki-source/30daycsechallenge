                                                             Challenge Objective
Create a menu-driven C program that lets a user choose a mathematical operation. After each operation, display the menu again. The program
must stop only when the user selects Exit.
                                                               Algorithm
Start.



Display the menu: Linear equation, Factorial, Quadratic equation, and Exit.



Read the user's choice.



If choice is 1, read a and b, solve the linear equation \(ax+b=0\), and display the result.



If choice is 2, read an integer, calculate its factorial using a loop, and display the result. Check that the number is between 0 and 12.



If choice is 3, read a, b, and c, calculate the discriminant \(d=b^2-4ac\), and display the real roots if they exist.



If choice is 4, display “Goodbye!” and exit.



If the choice is invalid, display an error message.



Repeat steps 2–8 until the user selects Exit.



Stop.
