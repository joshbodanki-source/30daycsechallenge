                                                        Challenge Objective
A smart-campus activity monitor records the number of visits over several time slots. Your task is to write a C program that studies the
sequence, finds meaningful patterns, and then rotates the data for a cyclic report. The important part is to plan the logic before coding
and to handle unusual cases correctly.
                                                          algorithm
Step 1: Start the program.

Step 2: Read N (between 5 and 12).

Step 3: Enter N numbers (between 0 and 1000) into an array. Ask again if any input is invalid.

Step 4: Display the original array.

Step 5: Calculate and display the sum, average, minimum and maximum.

Step 6: Find the second-largest distinct number. If all numbers are equal, display a message.

Step 7: Count the local peaks (numbers greater than both neighbours).

Step 8: Find the longest increasing run (consecutive numbers in increasing order).

Step 9: Read K and rotate the array. Positive K rotates right, and negative K rotates left.

Step 10: Display the rotated array.

Step 11: Enter the last two digits of the registration number (R).

Step 12: Calculate D = (R % 9) + 1 and count the numbers divisible by D.

Step 13: Display D and the divisible count.

Step 14: Stop the program.
